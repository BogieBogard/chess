# Greek Mythology chess — embedded set

[Chess Set – Greek Mythology Pieces](https://sketchfab.com/3d-models/chess-set-greek-mythology-pieces-10b53b9575294dfb915f8c0b5ea0a2fc) by [ahingel](https://sketchfab.com/ahingel), displayed in the official Sketchfab viewer with its original board, materials, lighting and attribution.

No model files are downloaded, extracted or redistributed by this integration. The existing chess rules remain authoritative. The public [Viewer API](https://sketchfab.com/developers/viewer/functions) moves individual piece transforms and hides captured pieces. Camera controls and projected legal-move/icon buttons connect the embedded scene to the game. Switching sets keeps the current game; undo restores captured pieces.

This optional beta requires the hosted Sketchfab viewer and an internet connection. Park/environment and lighter-graphics settings affect the locally rendered sets; the embed keeps the creator's scene and texture settings. If it cannot load, the previous set stays available.

The viewer cannot clone a piece mesh. For promotions beyond the available matching source models, an unused pawn represents the promoted piece with a persistent role icon, even when ordinary icons are off. The chess rules, promotion choices and undo still apply normally. This visual compromise was approved by Matt for the trial.

The fixture used by automated tests contains only publicly exposed node names and transform matrices, not geometry or textures.
