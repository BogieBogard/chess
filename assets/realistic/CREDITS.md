# Realistic Chess Set

**Creator:** BenAissa_Karim ([Sketchfab profile](https://sketchfab.com/BenAissa_Karim))

**Source:** [Realistic Chess Set – Full Board with Pieces](https://sketchfab.com/3d-models/realistic-chess-set-full-board-with-pieces-4f5a651ec0c7405badbcf478ed1cab8f)

**License:** [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/). The downloaded GLB embeds this attribution and license in its asset metadata.

**Modifications:** Six reusable piece meshes extracted from the supplied GLB; transforms baked, pieces centered on their bases and scaled to the existing game board. Positions quantized to 16-bit and normals to 8-bit. Original black/white material colors and surface parameters retained. Shared meshes replace duplicate pieces. The source board and its texture are excluded. No rig or animation was supplied; movement and captures use the game's simple animation system.

The original downloaded file remains unmodified. Run `scripts/extract-realistic-set.mjs` with that GLB to reproduce these files.
